## Тайминг (трек `C:\Users\yr4e\Downloads\teaser60c_v2_safe.mp3`)
Клип ставится на **16,80 с** трека. 1920×1080, 60 fps. Константы как в `BuildTurbine.tsx`:
`T0=16.8; at(s)=round((s-T0)*60); HIT=at(16.9); HUM=at(19.1); DROP=at(20.69); PULSE=0.12*60`.

| Время трека | Что в кадре |
|---|---|
| 16,90 | глубокий удар: на чёрный с грохотом падают первые **пушки** |
| 16,9 → ~17,7 | пушки сыплются; слева вверху **WEAPONS** и число 0 → **33**, +1 на каждую упавшую пушку |
| ~17,7 → ~18,5 | падают **карты**; строка **CARDS** под WEAPONS, 0 → **23** |
| ~18,5 → 20,6 | падают **предметы**; строка **ITEMS**, 0 → **85**. С 19,1 звон «а-А-а» (период 0,12 с): падение разгоняется, куча трясётся в такт |
| 20,69 дроп | вся сцена в размытие, поверх бьёт **1 BUILD / NOBODY PLANNED** (пиксельный шрифт), ~1 с хвоста |

Счётчик привязан к моменту приземления конкретного объекта, а не к таймеру. Если 141 объект слишком много — ронять меньше, число докручивать быстрее (спросить владельца).

## Как делать 3D (согласовано с владельцем по его эскизу)
- **Предметы и пушки** (PNG 256×256, пиксель-арт): экструзия силуэта. Каждый непрозрачный пиксель → кубик, глубина несколько пикселей. Перед = картинка, бок = цвет крайнего пикселя темнее, зад = зеркало переда. Это то, что владелец нарисовал стрелкой.
- **Карты** (PNG 224×304): тонкая плита-прямоугольник с гранями, лицо = картинка карты, зад тёмный.
- Стек: `three` + `@react-three/fiber` + `@remotion/three` (версия = remotion 4.0.534). Воксели — `InstancedMesh` (или merged geometry на иконку, строится из пикселей PNG один раз).
- Физика: детерминированная, предрасчитать один раз (`cannon-es` или своя Verlet как в `Overtime.tsx` `simulate()`), кешировать по кадрам. Remotion рендерит кадры не по порядку — никакого состояния между кадрами.
- Куча по эскизу владельца: широкая насыпь-«плато» с неровным верхом, а не конус.
- Свет: тёплый снизу/сбоку (оранжевый глоу как в варианте 2), тени, DOF, движение камеры медленно по дуге, motion blur на быстрых.
- Тряска кучи на пульсе 0,12 с после 19,1.

## Правила владельца (обязательно)
- Сначала **стоп-кадр из середины** (~18,6 с), анимация только после «да».
- Пиксельный шрифт только (`PixelText`, целый scale). Без белых вспышек. Без глитч-запов.
- Звуки не добавлять без просьбы (в треке всё есть).
- Работать локально, давать пути к файлам. Коммиты: автор Yr4e, ветка `overspam-teaser`, рендеры — в `overspam-renders`.
