# Задание для Codex: 3 объёмных объекта из пиксельных PNG

Проект: `D:\ndj-teaser-previs\overspam` (Remotion 4.0.534, React, 1920×1080, 60 fps). Общий контекст в `BUILD_PILE.md`.
Нужны **только 3 тестовых объекта**. Анимацию, физику и кучу делает Claude, не ты.

## Что сделать
1. Поставить зависимости: `npm i three @react-three/fiber @remotion/three@4.0.534` (+ `@types/three` в dev). Версия `@remotion/three` должна совпадать с `remotion`.
2. Файл `src/overspam/voxel.tsx`: функция/компонент, который берёт PNG и строит объёмную модель.
   - **Предмет / пушка** (PNG 256×256 пиксель-арт): каждый непрозрачный пиксель (alpha > 128) → кубик. Перед = цвет пикселя, боковые грани = тот же цвет темнее (~×0.55), зад = зеркало переда. Глубина: параметр `depth` в «пикселях», по умолчанию 3. Иконки апскейлены — сначала найди реальный размер пикселя арта (шаг, с которым цвет повторяется) и строй по нему, а не по 256×256.
   - **Карта** (PNG 224×304): тонкая коробка `BoxGeometry` с текстурой карты на лице (`NearestFilter`, без сглаживания), зад и торцы тёмные (#1a1420).
   - Сливать кубики одного объекта в одну геометрию (merged BufferGeometry или InstancedMesh), объектов будет ~150 в кадре, должно рендериться быстро.
   - Чтение пикселей PNG: детерминированно, асинхронно с `delayRender`/`continueRender` Remotion (или предрасчёт в JSON скриптом — на твой выбор).
3. Тестовая композиция `OS-VoxelTest` (зарегистрировать в `src/overspam/Compositions.tsx`, 180 кадров): три объекта в ряд на чёрном фоне `#06050b`, медленно вращаются по Y, чтобы было видно бока. Свет: тёплый оранжевый ключ сбоку-снизу + слабый холодный заполняющий, тени включены.
   - пушка: `public/overspam/game/256x256_six_shot.png`
   - предмет: `public/overspam/game/256x256_energy_drink.png`
   - карта: `public/overspam/game/224x304_damage_card.png`
   (если какого-то файла нет — взять соседний из той же папки и написать какой)
4. Отрендерить стоп-кадр для проверки: `npx remotion still OS-VoxelTest out/voxel_test.png --frame=40`.

## Ограничения
- Пиксели должны остаться чёткими квадратами (никакого сглаживания текстур).
- Не трогать другие композиции и файлы, кроме `Compositions.tsx`, `package.json`/lock и нового `voxel.tsx`.
- Ничего не коммитить и не пушить.
- В конце написать: какие файлы изменены, как вызывать компонент (props), размер пикселя арта, путь к `voxel_test.png`.
