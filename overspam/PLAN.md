## Видео 2. Полноценный обзор (по очереди всё, что есть в игре)

Длиннее (1,5–2 мин), спокойнее, рассказывает игру по разделам. Каждый раздел = полноэкранная вставка-заголовок + 6–15 с геймплея на эту тему + мини-подписи поверх. Кадры не из трейлера.

1. **Как играть**: бег, прыжок, слайд, оружие стреляет само, сбор опыта.
2. **5 миров**: `worlds.mp4`, затем по 3–4 с на каждый мир с подписью названия.
3. **12 героев**: `heroes.mp4`, затем ближний бой / дальний / магия / мобильность (Brakka, Wizzle, Grindbone, Cosmonaut…), подпись с пассивкой.
4. **Оружие**: `weapons.mp4`, крупно 5–6 разных пушек.
5. **Карты (левел-ап)**: вставка-нарезка рероллов (~3 с, как LEVEL UP у DRG), потом выбор и сразу оружие в бою.
6. **Предметы**: `items.mp4`, затем подбор предметов.
7. **Сундуки**: отдельная вставка ~2 с: 2–3 открытия по нарастанию, на последнем удар, счётчик выпавшего тикает.
8. **Ивенты на карте**: мини-вставки 1–1,5 с между клипами — `SHRINES`, `BOSS ALTARS`, `GOLD`, портал.
9. **Статы (TAB)**: начало забега и конец, «было → стало».
10. **Боссы**: 5 плашек `boss-1..5.mov` на стоп-кадрах.
11. **Overtime / бесконечный режим**: самый плотный хаос.
12. **Билд**: `build.mp4`, финальный монтаж, `end.mp4`.

Музыка: тот же трек, удлинённый `--jumps 12:9x2,20:17x2` (~73 с), или новый трек из ElevenLabs длиннее.
