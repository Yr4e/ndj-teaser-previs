# OVERSPAM: пайплайн тизера для Steam

Запуск: `cd overspam && npm install && npm run overspam` (нужен Node 20+, ffmpeg Remotion ставит сам). Пути ниже даны относительно папки `overspam/`. В этой копии звуки только свои, синтезированные (`public/sfx/foley`).

Игра: OVERSPAM, 3D survivor roguelite (overspam.com, билд в `D:\Overspam`).
Референс по монтажу: Deep Rock Galactic: Survivor, Xbox launch trailer. Склейки там стоят на ударах музыки, между геймплеем идут экраны игры (апгрейды, оружие, сектора, сложность с тикающим счётчиком), перед боссом пауза, в конце белая вспышка и карточка.

Картинки взяты из билда игры (`public/overspam/game`: логотип 60×14, пиксельный шрифт, иконки, карточки томов) и с overspam.com (`public/overspam/site`: герои, боссы, миры). Обновил игру — заново вытащи их скриптом из `scripts/overspam_extract.py` (см. ниже).

## Музыка: обрезать начало и удлинить

`python -I scripts/music_extend.py <трек.mp3> <выход> --start-bar 3 --jumps 12:9,20:17` (нужны Python с numpy и ffmpeg).
Режет и склеивает только по границам тактов, на швах короткий кроссфейд. Для `Combat_Surge_2026-10-31T135409.mp3` (130 BPM, первый такт 1,332 с):

- такты 7–13: основная часть, повторяется; `12:9` вставляет ещё 4 такта (+7,4 с);
- такт 14: провал музыки, место под паузу и плашку босса;
- такты 15–21: дроп; `20:17` вставляет ещё 4 такта;
- `12:9x2` — два повтора подряд.

Скрипт печатает, на какой секунде в новой версии стоит каждый такт, по этим отметкам ставь склейки.

## Настройки: `content/overspam/teaser.json`

- `bpm`: темп музыки. Все тики и удары считаются от него. Сейчас 130 (замерено по музыке в `черновик1.mov`, первый удар на 0,44 с). Новая музыка → поменять BPM → `npm run overspam`.
- `bg`: фон вставок: `grid` (свечение и сетка), `deep` (почти чёрный с зерном), `spot`, `crt`, `dust`. Сравнить: `npm run preview-bg` → `out/overspam/bg-*.png`.
- `noFlash`: вставки без белой вспышки на импакте.
- `end.world`: фон концовки, картинка мира: `forest`, `moon`, `deadnet`, `dunes` или `abyss`. Без него фон тёмный с сеткой.
- `end.line`, `end.button`, `end.site`: тексты концовки. Шрифт игровой, есть A–Z, 0–9, русские заглавные и `. , : ! ? + - / % ( ) [ ] = # & @`.
- Отрендерить только часть: `npm run overspam -- OS-End OS-Weapons`.
- Посмотреть и подвигать вживую: `npm run studio`, композиции `OS-*`.

## Как собрать тизер (около 60 с = 32 такта при 130 BPM)

Один такт при 130 BPM = 1,85 с, одна доля = 0,46 с. В CapCut включи метки битов (Beat → Auto) на музыке и клади склейки только на них.

1. **Хук, такты 1–2.** Тихо: один герой, мало врагов, музыка разгоняется. На удар бочки цифры урона заливают экран.
2. **`worlds.mp4`**, потом по 2 доли на каждый мир в порядке Forest → Moon → Dead Internet → Sunscar Dunes → Abyss Dome.
3. **`heroes.mp4`**, потом по одной доле на героя: ближний бой (Brakka, Bongo), дальний, магия (Wizzle), Grindbone на скейте.
4. **`weapons.mp4`**, потом 4–6 коротких кадров разного оружия (ракеты, молнии, лук, торнадо).
5. **`cards.mp4`** + запись настоящего экрана выбора карточек при левел-апе (у DRG это один из лучших кадров).
6. **`items.mp4`**, потом самый жирный хаос.
7. **Пауза перед боссом**, как у DRG: в музыке стоп на 1–2 такта. Стоп-кадр босса (Freeze 2–2,5 с) + `boss-N.mov` поверх, затем 2 такта боя.
8. **`build.mp4`** перед дропом. Дальше склейки всё чаще: по доле, потом по полдоли. Цифры урона растут.
9. **Белая вспышка** (у `end.mp4` она уже есть на падении логотипа), потом **`end.mp4`**.

## Как исправить `черновик1.mov` (42 с), не пересобирая всё

Склейки в черновике идут через каждые ~1,85 с, то есть ровно по такту. Вставку ставь вместо одного такта геймплея, тогда музыка не съедет:

- **на 4,4 с** (после второго клипа): `worlds.mp4`;
- **на 15,4 с**: `weapons.mp4`;
- **на 23–25 с** (Sun Pharaoh): стоп-кадр + `boss-4.mov`;
- **на 34,4 с**: `build.mp4`;
- **с 37,6 с**: старую картинку с COMING SOON заменить на `end.mp4`.

Таймер «10:00» на HUD висит на месте и выдаёт монтаж. Записывай реальный забег, чтобы таймер шёл, или обрежь верхнюю полосу.

## Список кадров для записи (60 fps, с HUD)

- Старт забега: один герой, пустое поле (для хука).
- По одному сочному кадру на каждый мир (5).
- Каждый герой за 1–2 секунды узнаваемого действия (12).
- Отдельное оружие крупно: ракеты, молнии, торнадо, лук, мины (5–6).
- Экран левел-апа с выбором карточек и экран сундука или шрайна.
- Каждый босс: появление (для стоп-кадра) и фаза атаки.
- Поздний Overtime: максимум врагов и цифр (для дропа).
- Портал между мирами (красивый переход).
